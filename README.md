
Excel Sales Analysis Project

Project Overview

This project analyzes sales data using Microsoft Excel to organize data, perform calculations, and present information through a dashboard.

Tools Used

- Microsoft Excel
- Excel formulas and calculations
- Charts and data visualization
- Dashboard creation

Workbook Sheets

- Raw Data: Contains the practice sales dataset.
- Calculations: Contains calculations used for the analysis.
- Dashboard: Presents the sales analysis visually.

Project Objective

To practice data analysis skills, summarize sales data, and present useful information through charts and a dashboard.

Dataset

Practice dataset sourced from the internet.

Project File

Excel workbook: "Excel_Sales_Analysis.xlsx"

Key Insights
-Total Revenue Generated: ₹750.18 Million across all markets and products.
-Total Boxes Sold: 669,020 units, indicating strong product demand.
-Sales Team Strength: Dashboard tracks performance of 25 sales representatives.
-Average Revenue per Salesperson: ₹30.01 Million, providing a benchmark for individual performance evaluation.
-Country-wise Performance Analysis: Sales data is segmented across Australia, Canada, India, New Zealand, UK, and USA for regional comparison.
-Salesperson Performance Tracking: Enables identification of top-performing and underperforming sales representatives through interactive visualizations.
-Product-wise Sales Monitoring: Performance can be filtered by individual chocolate product categories, supporting product portfolio analysis.
-Interactive Filtering: Dynamic slicers for Salesperson, Product, and Country allow detailed drill-down analysis.
-Comparative Sales Analytics: Visual charts highlight revenue distribution by country and salesperson, helping uncover sales trends and opportunities.
-Business Decision Support: Dashboard provides a centralized view of sales KPIs for data-driven decision making
